# Выбранный датасет

## Название

NYC TLC Trip Record Data — High Volume For-Hire Vehicle Trip Records

## Источник

Официальный источник данных: NYC Taxi & Limousine Commission, раздел TLC Trip Record Data.

Страница датасета:

https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

## Формат данных

Parquet.

## Выбранный набор

Для проекта выбран набор High Volume For-Hire Vehicle Trip Records. Данные публикуются помесячно в виде отдельных Parquet-файлов.

## Объём данных

Для выполнения требования по объёму планируется использовать несколько месячных файлов High Volume For-Hire Vehicle Trip Records. Общий объём выбранных файлов превышает 1 ГБ.

Рекомендуемый набор файлов для следующего этапа:

- fhvhv_tripdata_2024-01.parquet
- fhvhv_tripdata_2024-02.parquet
- fhvhv_tripdata_2024-03.parquet

При необходимости объём можно увеличить, добавив следующие месяцы 2024 года.

## Содержание данных

Датасет содержит сведения о поездках сервисов high-volume for-hire vehicles в Нью-Йорке. В данных представлены сведения о времени начала и окончания поездки, зонах посадки и высадки, поставщике услуги, расстоянии поездки, стоимости, налогах, сборах, чаевых и других параметрах.

## Почему датасет подходит для проекта

Датасет подходит для учебного проекта Data Lakehouse, потому что имеет большой объём, открытую структуру, хранится в формате Parquet и может быть использован для построения аналитических витрин. Данные позволяют анализировать динамику поездок, спрос по районам, временные пики, стоимость поездок и распределение заказов по провайдерам.

## Возможные аналитики для следующих этапов

На основе этого датасета можно построить следующие витрины:

- количество поездок по дням и месяцам;
- распределение поездок по районам посадки и высадки;
- анализ пиковых часов спроса;
- средняя стоимость поездки;
- средняя длительность поездки;
- среднее расстояние поездки;
- сумма сборов и чаевых;
- сравнение активности по провайдерам;
- динамика спроса по периодам.
